# 本地网页版

## 启动

在仓库根目录运行：

```sh
python -X utf8 web_ui.py
```

然后用浏览器打开 `http://127.0.0.1:8765`。默认端口被占用时使用 `--port 8767`；权重可用 `--model-dir checkpoints` 指定目录。关闭服务用 Ctrl+C。服务监听本机 127.0.0.1。

默认启发式 AI 只依赖 NumPy；选择神经网络后需要项目的 PyTorch 环境。页面文件由本地 Python 服务提供。

## 对局操作

- 选择执黑/执白、AI 模型和每方分钟数，点击开始。黑方首回合只下一子，其余回合每方两子；每点一次交叉点下一子，下一子前即检查胜负。
- 默认启发式 AI 无需权重，检查本回合两子获胜和对手两子威胁，再比较候选组合及对手应手，详见 [启发式策略](HEURISTIC.md)。神经网络从指定目录的 `.pt` 文件中选择，支持 CPU / CUDA / 自动选择，搜索次数 1--2000。
- 开局库默认开启，读取仓库根目录的 `connect6_book.pkl`。每落一子后重新查库，支持旋转和镜像匹配；未命中或缺少文件时使用所选 AI。落子记录中的“库”表示开局库应手，导出棋谱的 `source` 字段记录 `human`、`book` 或 `ai`。开关在开始新局时生效。
- 模型在首次需要搜索时后台加载并思考。首次加载耗时也计入 AI 用时。思考时禁用人类落子，但可重新开始或悔棋；旧搜索完成后不会写入新棋局。
- 悔一步回到上一次人类落子之前，同时撤销随后发生的 AI 应手，并恢复该时刻计时。两子回合内可以仅撤回最近一子。AI 开局前没有人类落子时无法悔棋。
- 达到六连、满盘或一方超时即结束。模型加载或搜索失败时暂停本局，并显示错误提示。
- 导出 JSON 棋谱保存到浏览器下载目录，包含设置、逐子坐标/颜色和结果。行列从 0 开始，文字坐标 A--S / 1--19 以左下角为原点。
- 棋盘支持方向键移动焦点、回车或空格落子，窄屏下设置面板排列在棋盘下方。

## 实现

后端用 Python 标准库 ThreadingHTTPServer，棋盘复用 Connect6Env。启发式对手复用 HeuristicAI；神经网络通过 Connect6Player 使用原网络和 MCTS。页面定期读取状态，搜索在线程中执行，并以对局版本号丢弃已取消任务的结果。取消会阻止落子，但不能强行终止正在运行的一次模型推理；新搜索需等待旧推理释放执行锁。

服务维护一局共享棋盘，同一服务的浏览器标签操作同一盘棋。刷新页面保留棋局并重置表单；停止 Python 后棋局清空，保存对局使用导出按钮。网页版提供人机对弈，比赛操作见桌面 GUI。

## 验证

```sh
python -X utf8 -B -m unittest discover -s tests -v
```

自动检查覆盖回合切换、悔棋、取消任务、超时、非法请求、模型失败、棋谱坐标和 HTTP 接口。桌面浏览器验证包含启发式落子、悔棋、JSON 下载、刷新保留棋局，以及 `final_model.pt` 的 CPU 加载和落子。

Katagomo 引擎对弈、SGF/JSON 导入与逐步复盘使用独立的 [Katagomo 界面](KATAGOMO.md)，默认端口 8766。
